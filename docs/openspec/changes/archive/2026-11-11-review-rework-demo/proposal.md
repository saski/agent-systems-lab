# Add G02 to the saved Review Capacity demo

## Why

G02 has verified results but the existing public demo still presents only the
original A/B/C experiment. Readers need to inspect the same task under FIFO and
correction priority, including the waits hidden by the lower overall mean.

## What Changes

Add a G02 section to the existing standalone demo, preserving the A/B/C replay
and its anchors. Embed the verified G02 trace, show cohort metrics, synchronize
both policies on one logical clock and compare a selected task's timelines.
Keep the page self-contained, accessible on narrow screens and usable with
reduced motion. Copy the resulting artifact to the existing website demo path.
Public Notes and LinkedIn text remain proposals for the author's review.
